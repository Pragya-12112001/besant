CSS Positioning

CSS positioning controls where an element appears on the page. The main position values are static, relative, absolute, fixed, and sticky.

1. Static Position

Static is the default position of an HTML element. The element follows the normal document flow.

Static

2. Relative Position

Relative keeps the element in its normal position, but allows us to move it using top, right, bottom, or left.

Relative

3. Absolute Position

An absolute element is removed from the normal document flow. It is positioned relative to its nearest positioned parent.

Absolute

4. Z-Index

z-index controls which positioned element appears in front of another element.

Box 1
Box 2

5. Fixed Position

A fixed element stays attached to the browser window. It does not move when the page is scrolled.

Fixed Example

6. Sticky Position

A sticky element behaves normally until it reaches a specified position, after which it sticks there while scrolling.
