HTML Notes

A simple guide to understanding HTML and its basic tags.

1. What is HTML?

HTML stands for HyperText Markup Language. It is a markup language used to create the structure and content of webpages.

HTML is not a programming language. It tells the browser what different types of content represent. 

HTML
 |
 +-- Text
 +-- Images
 +-- Audio
 +-- Video

2. Tags, Elements & Attributes

HTML Tag

A tag is written inside angle brackets and tells the browser what type of content it represents. 

<p>
<h1>
<img>

HTML Element

An element is the complete structure containing the opening tag, content, and closing tag. 

<p>Hello World</p>

Tag      → <p>
Content  → Hello World
Element  → <p>Hello World</p>

HTML Attribute

Attributes provide additional information about an element. They are written inside the opening tag. 

<img src="image.jpg" alt="HTML Logo">

src → image location
alt → alternative text

3. Basic HTML Tags

3.1 Heading Tags

HTML provides six heading levels, from h1 to h6. 

<h1>Main Heading</h1>
<h2>Section Heading</h2>
<h3>Subsection</h3>
<h4>Heading 4</h4>
<h5>Heading 5</h5>
<h6>Heading 6</h6>

H1 Heading

H2 Heading

H3 Heading

H4 Heading

H5 Heading
H6 Heading

3.2 Paragraph Tag

The p tag is used to display a paragraph of text. 

<p>This is a paragraph.</p>

This is an example paragraph created using HTML.

3.3 Preformatted Text

The pre tag preserves spaces and line breaks. It is useful for code and formatted text. 

Name       Age       City
-------------------------
Rahul      22        Delhi
Priya      21        Mumbai
Aman       23        Raipur

3.4 Image Tag

The img tag is used to display an image. 

<img src="image.jpg" alt="HTML Logo">

src → specifies the image location
alt → describes the image

3.5 Audio Tag

The audio tag is used to add audio to a webpage. 

<audio controls>
    <source src="audio.mp3" type="audio/mpeg">
</audio>

The controls attribute displays play, pause, volume, and other audio controls.

3.6 Video Tag

The video tag is used to add video to a webpage. 

<video controls width="500">
    <source src="video.mp4" type="video/mp4">
</video>

controls → displays video controls
width → specifies the video width

4. Quick Reference

Tag        Purpose
--------------------------------
h1 - h6   Headings
p         Paragraph
pre       Preserves formatting
img       Displays image
audio     Adds audio
video     Adds video

<h1>My Website</h1>

Show Answer

A main heading "My Website", followed by a paragraph and an h2 heading "About Me".

Find the Mistake

<img>

What is missing?

Show Answer

The image needs a src attribute to specify which image should be displayed. 

<img src="image.jpg" alt="My Image">
