1. Introduction to Flexbox

Flexbox stands for Flexible Box Layout. It is a CSS layout system used to arrange elements, control spacing, align items, and distribute available space within a container.

It is useful for navigation bars, buttons, cards, sidebars, and responsive page sections.

The parent becomes a flex container, and its direct children become flex items.

2. Main Axis and Cross Axis

Flexbox arranges items along two axes. Understanding these axes is essential before learning alignment properties.

  • Main axis: The direction in which flex items are laid out.
  • Cross axis: The direction perpendicular to the main axis.

Default direction: row

With flex-direction: row, the main axis is horizontal and the cross axis is vertical.

With flex-direction: column, the main axis becomes vertical and the cross axis becomes horizontal.

Remember: justify-content works along the main axis; align-items works along the cross axis.

3. Flex Container Properties

3.1 display

.container {
    display: flex;
}

Activates Flexbox for the element's direct children. Use display: inline-flex when the container itself should behave like an inline-level element.

3.2 flex-direction

  • row: Left to right in the usual writing direction.
  • row-reverse: Reverse horizontal direction.
  • column: Top to bottom.
  • column-reverse: Reverse vertical direction.
.container {
    display: flex;
    flex-direction: column;
}

3.3 justify-content

Distributes items along the main axis.

  • flex-start: Beginning of the main axis.
  • flex-end: End of the main axis.
  • center: Center of the main axis.
  • space-between: Space between items.
  • space-around: Space around items.
  • space-evenly: Equal spacing between items and edges.

Visual example: space-between

One
Two
Three
.container {
    display: flex;
    justify-content: space-between;
}

3.4 align-items

Aligns items along the cross axis.

  • stretch: Stretches eligible items.
  • flex-start: Aligns at the cross-axis start.
  • flex-end: Aligns at the cross-axis end.
  • center: Centers items.
  • baseline: Aligns text baselines.
.container {
    display: flex;
    align-items: center;
    min-height: 200px;
}

3.5 flex-wrap

Controls whether items stay on one line or wrap onto multiple lines.

.container {
    display: flex;
    flex-wrap: wrap;
    gap: 10px;

  • nowrap: Single flex line (default).
  • wrap: Allows additional lines.
  • wrap-reverse: Reverses the cross-axis stacking direction of flex lines.

3.6 align-content

Controls the distribution of multiple flex lines along the cross axis when wrapping occurs and extra space is available. 

.container {
    display: flex;
    flex-wrap: wrap;
    align-content: space-between;
    min-height: 350px;
}

Common values include center, flex-start, flex-end, space-between, space-around, space-evenly and stretch. It has no meaningful multi-line distribution effect when there is only one flex line.

3.7 gap

Creates spacing between items.

.container {
    display: flex;
    gap: 20px;

    /* Or define separate gaps */
    row-gap: 15px;
    column-gap: 25px;
}

3.8 flex-flow

A shorthand for flex-direction and flex-wrap. 

.container {
    display: flex;
    flex-flow: row wrap;
}

4. Flex Item Properties

These properties are applied to individual flex items, rather than to the parent container.

4.1 order

Changes the visual order of items. The default value is 0. 

.item-special {
    order: -1;
}

4.2 flex-grow

Determines how available positive free space is distributed among items. 

.item-one {
    flex-grow: 1;
}

.item-two {
    flex-grow: 2;
}

4.3 flex-shrink

Determines how items shrink when their base sizes exceed the available space. 

.item {
    flex-shrink: 1;
}

A value of 0 prevents shrinking through the flex-shrink calculation. Other values determine relative shrink factors, taking item base sizes into account.

4.4 flex-basis

Specifies an item's initial main-axis size before free space is distributed. 

.item {
    flex-basis: 200px;
}

4.5 flex shorthand

Combines flex-grow, flex-shrink and flex-basis. 

.item {
    flex: 1;
}

4.6 align-self

Overrides the container's align-items setting for an individual item. 

.special-item {
    align-self: flex-end;
}
Flexbox alignment is relative to the axes. Changing flex-direction changes which physical direction is the main axis.

7. Quick Revision

  • display: flex activates Flexbox.
  • flex-direction controls the main axis direction.
  • justify-content distributes items on the main axis.
  • align-items aligns items on the cross axis.
  • flex-wrap allows items to wrap.
  • align-content distributes multiple flex lines.
  • gap creates spacing between items.
  • flex-grow distributes positive free space.
  • flex-shrink controls shrinking.
  • flex-basis sets the initial main-axis size.
  • align-self overrides one item's alignment.
  • order changes visual ordering.

Learning tip: Experiment with one property at a time. Predict the result, change the CSS, and observe how the layout changes in your browser.
